I'm an information systems researcher. The code here is tooling I built because my research and teaching needed it.

## Research tooling

- [scopus-plus-mcp](https://github.com/michalhron/scopus-plus-mcp): MCP server for Scopus with bibliometric analysis, citation lineages and main path computation. Its Claude Code plugin ships a main-path skill.
- [new-outlook-mcp](https://github.com/michalhron/new-outlook-mcp): read-only MCP server that searches Outlook for Mac mail and calendar from the files Outlook already keeps on disk.
- [mcp-hey](https://github.com/michalhron/mcp-hey): my fork of the HEY email MCP server, with a local .eml archive of the messages you read and filters by sender group.

## Teaching

- [ArchiTrek](https://github.com/michalhron/ArchiTrek): finds and explains the legal ArchiMate 3.2 relationship paths between two element types. I use it in my MSc course on Enterprise Architecture. [Open it](https://architrek.hronmichal.net).
